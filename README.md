# feedback-review-aggregator-mern
# Feedback & Review Aggregator Platform

Open **README-HINGLISH.md** for beginner-friendly step-by-step installation instructions in Hinglish.

This is a MERN project (MongoDB Atlas, Express, React, Node.js) with review CRUD, search, category filter, sorting, helpful counts, rating statistics and responsive design.

Before running, create `backend/.env` from `backend/.env.example` and add your own MongoDB Atlas connection URI. Never share the actual `.env` file.
